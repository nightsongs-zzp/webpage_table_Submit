# 实验数据表格 同步器（油猴脚本）

把近代物理实验平台 `experiment.html?id=NN` 里 **4.1 数据记录表**（这个实验是 5 张表 / 341 格）导出到本地文件夹，
在本地（JSON 或 Excel）改完之后再**安全地回传**到网站。

> 方案：**油猴脚本（Tampermonkey / Violentmonkey）**，单文件、零依赖安装（SheetJS 由 `@require` 自动拉取）。
> 本地格式：**JSON（主存档，无损）+ XLSX（每张表一个工作表，方便手算）**。

---

## 一、安装（一次性，约 1 分钟）

1. 浏览器装 **Tampermonkey**（篡改猴）扩展：Edge/Chrome 应用商店搜 "Tampermonkey"。
2. 打开本文件：`webpage-table-sync.user.js`，全选复制。
3. 点 Tampermonkey 图标 → **添加新脚本** → 全选删掉模板 → 粘贴 → **Ctrl+S 保存**。
4. 打开网站 `http://<服务器地址>:8081/public/experiment.html?id=NN` 并登录，
   页面右上角会出现蓝色面板 **「表格同步器 exp NN · v1.2.0」**（可拖动标题栏移动）。

> 换服务器：改脚本头部 `@match`（2 行）与 `@connect`（1 行）里的地址即可，共 3 处。

**让文件直接落进本仓库的 `data/` 文件夹**（两选一）：

- **做法 A（推荐，最省事）**：浏览器 → 设置 → 下载内容 → 位置改成
  `D:\桌面\学习pro\实验\近物实验\test\data`，并**关闭「下载前询问每个文件的保存位置」**。
  之后每次点导出，文件直接进 `data\`，再把前缀改成 `exp17_` 就是 `data\exp17_20260919_1501.xlsx`。
- **做法 B（文件名分组）**：保留「下载前询问」，在面板里把 **自定义文件名** 填成 `exp17`（或 `exp17_data`）。
  这样固定输出 `exp17.xlsx` / `exp17.json`，同名直接覆盖，不会在下载目录里堆一堆时间戳副本 ——
  重命名一次拖进 `data\exp17\` 即可。

> ⚠️ 浏览器出于安全**不允许网页脚本直接写你硬盘上的任意路径**，所以"指定文件夹"这一步靠上面的下载目录设置实现，
> 这是方案 A 唯一的妥协点。（如果你后面想要"脚本自己写进指定目录/批量跑"，那就是当初说的方案 B（Playwright），随时可以加。）

## 二、日常用法（三步）

### 1️⃣ 导出

打开实验页 → 面板点 **「导出 JSON（主存档）」** 和/或 **「导出 XLSX」**。

- **JSON**：无损主存档。所有单元格原文都在，包括 `$1.5\times10^{-4}$` 这类 LaTeX、含 `|` / `,` / 前后空格的文本。
  做备份、跨设备搬运、精确计算都用它。
- **XLSX**：每张表一个工作表（`T0_表名`、`T1_表名`…），另外几张：
  - `说明_README`：给你看的用法说明；
  - **`_基线`**：导出那一刻的**服务器快照**，是回传时做三方合并的基准。**不要改它**。
  - **`_预设`**：模板自带的**预置单元格**快照（如"序号"列里印好的 1、2、3…）。用来判断
    "这一格到底是你填的、还是模板本来就有"。**也不要改它**。
  - **`_预置值清单`**：把所有"模板预置、永不上传"的格列成一张表（表/行/列/列名/预置值），一眼可查。

  **每张表都被两条边界横幅框起来**（这就是"表格区 / 非表格区"的分界线）：

  ```
  ▬▬▬ 数据区 (表 id=1) 开始 ▬▬▬                    ← 上边界（整条浅蓝底）
  表 id=1  表1：升温过程原始数据记录
  序号 │ 铂电阻温度计电压 $V_{Pt}$ (mV) │ … │ ┃     ← 列名 + 行尾边界列
  1    │                                  │ ┃     ← 数据行（每行尾巴都有 ┃）
  …                                              │
  ▬▬▬ 数据区 (表 id=1) 结束（下方内容不属于表格…）▬▬▬  ← 下边界
  ↑ 上面是「表 id=1」的数据区。本工作表下方请勿书写内容。
  ```

  - **两条横幅之间**才是会被采集的表格数据；横幅之外你写什么都不上传。
  - **千万不要删横幅、也不要改行尾的 `┃` 列** —— 它们既是视觉分界线，也是行号的"撑杆"：
    Excel 会把"整行全空"的行直接省略，靠这一列才能保证空行不被吞掉（否则导入时行号会错位）。
  - 老版本导出的文件（没有横幅）仍然能正常导入。

### 2️⃣ 本地改

- 只改两条横幅**之间**的数据行。
- **可以用 Excel 公式**：脚本读的是公式的**计算结果**，不会把 `=A1/B1` 这种文本上传。
  前提是该文件被 Excel/WPS 打开并保存过（公式结果已缓存）；没算过的话该格会读成空并给提示。
  想彻底避免歧义，建议算好后「选择性粘贴 → 值」。
- **LaTeX 请填原文**（如 `I_0/T^{2}` 外面套 `$…$`），别指望 Excel 帮你排版。
- **想清空服务器上的某一格** → 把那格内容删成**空**。（JSON 里也可以显式写 `__CLEAR__`。）
- **想保留服务器原值 / 模板预置值** → 那一格**一个字都别动**。
- 模板预置格（例如序号列）按约定**永不上传**；删成空也没用（模板会自动回落显示），要覆盖就直接填新值。

### 3️⃣ 导入上传

面板点 **「导入上传」** → 选你改好的 `.json` 或 `.xlsx` → 脚本先弹一个**差异预览**：

```
将修改 3 格 · 新增 12 格 · 清空 1 格，涉及 2 张表。
表 id=0：16 处改动
  [修改] (第3行,第2列)  1800 → 1880
  [新增] (第3行,第3列)  (空) → $2.3\times10^{-4}$
  [清空] (第5行,第1列)  0.5 → (空)
```

确认无误再点 **「确认上传改动」**。脚本随后自动：

1. **备份**服务器当前数据到浏览器本地（同一实验保留最近 6 份）；
2. `POST /api/student/data-record` 写入；
3. **回读校验**：重新 GET 一次，逐格比对上传内容；
4. 校验通过 → 提示成功；发现不一致 → 报警并建议回滚。

出问题就点 **「回滚上次」**，选一个时间点整份写回去。

## 三、它到底改了什么、没改什么（安全边界）

| 场景 | 行为 |
|---|---|
| **模板预置格**（该格当前模板有预置值、且服务器上从没存过） | **永不入库**：文件里这格是什么都不上传，页面靠"服务器值 → 模板预置值"回落显示。**你把它删空也不会生效**（模板会照旧显示），想覆盖就直接改成别的值 |
| 文件里**没动过**的格（值 == `_基线`） | **不上传**，服务器原值分毫不动 |
| 文件里**改了值**的格 | 上传新值 |
| 文件里**改成空**的格（服务器上真实存过值） | 视为「清空这一格」，上传空字符串 |
| 文件里写 `__CLEAR__`（JSON） | 强制清空这一格（预置格同理不入库） |
| 文件里**服务器上没有的表 id** | 整表跳过 + 日志告警，绝不新建/覆盖 |
| 文件里**缺某张表** | 那张表**不动**（不存在"删表"操作） |
| 表集合不一致（接口模板 ≠ 服务器已存） | **以服务器已存数据为准**，多出来的模板表不导出也不回传（避免凭空长出表） |
| Excel **缺 `_基线` 工作表**（手工做的表） | 降级为「只补空缺」：只写服务器为空的格，**绝不覆盖**已有值；冲突写进日志。预置格同样不入库 |
| 勾选 **严格覆盖（危险）** | 按文件内容整份写入，**空单元格会清空服务器数据**（此模式**不**保护预置格）；执行前二次确认 |

**关于"模板预置格"**：它们是老师模板里印好的内容（序号列 1…12、表4/表5 里"转变前正常态电阻""样品材料"这类），
在服务器上**从来没有存过**，页面上是靠回退显示出来的。本脚本按约定**永不把它们写进服务器**，好处是：
老师之后改了模板，你这边刷新就能看到最新模板内容，不会被你之前的保存"盖住"。
想知道具体哪些格属于这一类，看导出 XLSX 里的 **`_预置值清单`** 工作表（或差异预览里那句"另有 N 格是模板预置值"）。

**必知的一条**：页面上自带的「保存」按钮（`saveDataRecord`）是**从弹窗 DOM 逐格读值**的，
所以**弹窗没打开时点它，会把全部表格写成空**（页面源码 `experiment.js` 第 1348–1371 行就是这个逻辑）。
本脚本**不走这条路**：上传时以"服务器全量"为底、只覆盖你改动的格，因此**不需要打开弹窗**，也不会误清空。
（导出用的表定义来自 `/api/experiment/{id}` 的 `dataTableDefinition`；拿不到则退回弹窗 DOM。）

## 五、排错

| 现象 | 处理 |
|---|---|
| 面板没出现 | 确认 URL 是 `.../public/experiment.html?id=...`；点 Tampermonkey 图标看脚本是否启用；F12 控制台搜 `[WTS]` |
| **先确认装的是哪一版** | 面板标题右侧有 `v1.1.2`；点「诊断」会打印 `本脚本能力自检：rowCells=有 mapLike=有 …`，缺哪个就是旧版，**重新粘贴本文件覆盖脚本**再刷新页面 |
| **点了「确认上传改动」没反应 / 没日志** | v1.1.0 的已知 bug（确认点击被自己的 busy 挡掉），v1.1.1 已修。装新版即可 |
| 报 `Cannot read properties of undefined (reading 'length')` | 这是 v1.0.0 的已知崩溃（服务器把行的 cells 存成裸数组）。v1.1.0 已修；装新版即可 |
| 预览显示"新增几十格"但我没改那么多 | 那些是**模板预置格**（序号列、表4/表5 里印好的参数名）。v1.1.2 起它们**不再入库**；若你看到这条说明装的是旧版 |
| 删掉某格但刷新后值又回来了 | 那一格是**模板预置值**（服务器上没存过），按约定删不掉；想改就直接填新值 |
| 提示"未登录 / 会话过期" | 先在网页上正常登录（脚本复用浏览器 cookie），点「诊断」复核 |
| 导出时报"没有可导出的表" | 点「刷新服务器数据」；仍不行就点「诊断」，看是否 `dataTableDefinition` 字段名变了 |
| 导出的表比网页上少/多 | 看日志里 `表基准 = 服务器已存数据（…）；接口模板（…）` 那一行；两边不一致时脚本以**服务器已存数据**为准，并在日志里说明 |
| XLSX 导出失败（SheetJS 未加载） | 用「导出 JSON」；或检查 Tampermonkey 设置里是否允许 `@require`（需要联网首次拉取） |
| 上传后提示回读不一致 | **立即点「回滚上次」**，然后把「复制日志」的内容发我 |
| 想换个部署地址 | 改脚本头部 `@match` / `@connect` 两行，重新粘贴保存 |

## 八、更新记录

**v1.2.0**

- **兼容 Excel 公式**：导入 `.xlsx` 时，公式格一律取**公式的计算结果**（SheetJS 的 `cell.v`），
  不再可能把 `=A1/B1` 这种文本当数据上传；有公式时日志会提示"已按公式结果读取 N 格"。
  若某格读出来是空的，说明该文件没被 Excel/WPS 保存过、公式结果还没算出来（会有提醒）。
- **分区边界线**：导出的每张表被两条横幅夹住（`▬▬▬ 数据区 (表 id=N) 开始/结束 ▬▬▬`，带浅蓝底纹），
  行尾另有一列 `┃` 边界标记；导入时只采集两条横幅之间的内容，**横幅之外写什么都不上传**。
  边界列同时是"空行撑杆"——Excel 会省略整行全空的行，靠它才能保证空行不丢、行号不错位。
- **空行不再被丢弃**：行号 = 数据集 row 索引，之前丢弃空白行会让后面整列错位、被误判成"清空"。
  现在逐行原样保留（含全空行），彻底消除这一类误删风险。
- **修 `!ref` 少一列**：`aoa_to_sheet` 只看已有单元格决定范围，行尾边界列若为空会被整列吃掉，现在强制按行列数补齐。
- **去掉个人信息**：脚本头部不再带 GitHub 用户名（`@namespace` 改为本地标识、`@author` 置空）；
  含会话 cookie / 服务器地址的抓包笔记已从工作区删除并从索引移除；新增 `npm run scan:privacy` 自检。

**v1.1.2**（按你的要求改语义：**模板预置格永不入库、只靠模板回落**）

- **改动**：判定"这是不是模板预置格"改用**当前模板**（`/api/experiment/{id}` 的 `dataTableDefinition`），
  而不是文件里的 `_预设` 快照 —— 因为模板可能在导出之后被改过，那样文件里对应格会是空的，用快照就会漏判。
- **行为**：预置格（服务器上从没存过、当前模板有值）无论文件里是什么都**不上传**：
  - 未改动 → 跳过；
  - **删成空 → 也跳过**（模板会照旧回落显示，所以"删预置值"这个动作等于无效，这是该语义的必然结果）；
  - 改成别的值 → 照常上传（覆盖模板回落）。
- **附带修正两个误判**（都是这一轮才暴露的）：
  1. `_baseline` 存的是**导出视图**（含预置回落值），导致"改预置格"被误判成「修改」而不是「新增」——
     现在归类看**服务器上原来有没有值**，不再看基线；
  2. 同理，未改动的预置格会被基线比较提前 `continue`，导致 `presetSkipped` 计数虚低（差异预览里白丢一句提示）——
     现在预置判定排在基线比较**之前**，计数准确。
- **预览提示**：差异预览会多一句"另有 N 格是「模板预置值」，按约定不入库"。
- **XLSX 新增 `_预置值清单` 工作表**：列出所有"模板预置、永不上传"的格（表/行/列/列名/预置值），一眼可查。

**v1.1.1**（修一个"点了确认却什么都不发生"的严重 bug）

- **现象**：导入时差异预览弹窗正常弹出，但点「确认上传改动」后**没有任何日志、没有上传**，然后弹窗关闭；
  之后再点「导入上传」还会提示"已有操作在进行中"。
- **原因**：`importFile()` 在等待弹窗结果的整个期间会把 `busy` 置为 `true`（本意是挡住重复点「导入上传」），
  而 `commitImport()` 开头又用 `S.busy` 当守门员 —— **它把自己的确认点击挡回去了**。
- **修复**：`commitImport` 改用独立的 `committing` 标志；弹窗期间确认/取消按钮会置灰并显示「上传中…」，
  防止连点造成重复上传。新增 `tests/test-ui-flow.js` 用真 DOM 覆盖这条路径（**这类 bug 只有真 DOM 才测得出**）。

**v1.1.0**（修 3 个真实问题）

1. **修崩溃**：服务器 `table_data.tables[].rows` 的元素可能是**裸数组** `["1","2"]` 而不是 `{"cells":[...]}`，
   v1.0.0 的 `expCols()` 会在 `r.cells.length` 处抛 `TypeError: Cannot read properties of undefined (reading 'length')`。
   现在两侧行形态在入口统一收口成 `{cells:[...]}`（`rowCells()` / `normRows()`），并且纵深防御到 `buildUploadTables`。
2. **修数据丢失**：模板自带的**预置单元格**（如"序号"列印好的 1…12）在服务器上并未保存，v1.0.0 导出时只读服务器值
   → 预置数据全丢。现在导出按「服务器值 > 模板预置值 > 空」回落（与页面显示口径一致），
   并把预置层写进文件（JSON 的 `_presets` / XLSX 的 `_预设` 工作表），避免导入时把模板数据当成"你填的"上传。
3. **修表集合错配**：接口模板与服务器已存数据的表集合可能不一致（实测 exp22：模板 6 张 vs 已存 8 张）。
   现在**一律以服务器已存数据为准**，并在日志里显式打印两边差异，避免凭空往服务器加表。
   另外修掉"用户把预置格删空却被静默忽略"的语义漏洞（现在会真的写空）。

## 九、已知局限（说在前面）

1. **XLSX 不是无损通道**：Excel 可能把 `1.5e-4` 存成数字、把超长数字转科学计数法。脚本读回时做了尽力还原，
   但**精确数值请以 JSON 为准**；`_基线` + `_预设` 两层快照保证这种类型漂移**不会**被误判成"你改了数据"。
2. **不能自动写任意目录**：受浏览器沙箱限制，只能通过"下载目录 + 文件名"控制落点（见第一节）。
3. **删除整个工作表 ≠ 删表**：脚本不会因为文件里少一张表就删服务器上的表（这是故意的安全设计）。
4. **只覆盖了这一个站点的这一个接口**：换站点要改 `@match`、`@connect`，以及 `extractDefs()`
   里的字段名候选列表。
